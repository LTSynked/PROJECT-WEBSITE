Module 1: Intro to Web Dev

Overview of what web development is, how websites work, and the roles of HTML, CSS, and JavaScript.

Module 2: Intro to HTML

Learn the structure of a webpage using HTML elements such as headings, paragraphs, links, and lists.

Module 3: Intro to CSS

Style your website using colors, fonts, spacing, and layouts with Cascading Style Sheets.

Module 4: Website Images

Using images properly with <img>, formats, sizes, and accessibility.

Module 5: Positioning and Navigation

Learn CSS positioning, flexbox basics, and create navigation menus.

Module 6: Responsive Websites

Make your website look good on mobile, tablet, and desktop using media queries.

Module 7: Tables and Forms

Create tables for data and forms for user input like login or contact forms.

Module 8: Careers and Multimedia

Explore web dev careers and embed videos and audio into websites.

Module 9: Ecommerce and SEO

Basics of online stores and how search engines find and rank websites.

Module 10: JavaScript

Add interactivity using JavaScript such as buttons, alerts, and simple logic.

Module 11: Frameworks and Bootstrap

Introduction to frameworks and how Bootstrap speeds up development.

Module 12: Design and Galleries

Design principles and image galleries for better visual presentation.

Module 13: Logo and Header

Create a strong website identity with logos and headers.

Module 14: Publishing

Learn how to publish your website online using hosting services.
